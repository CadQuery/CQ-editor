# Fonts

Latin subsets of the user interface fonts, embedded in the executable:

| File | Font | License |
| --- | --- | --- |
| `Inter-Regular.ttf`, `Inter-SemiBold.ttf` | [Inter](https://rsms.me/inter/) | SIL Open Font License 1.1, see `Inter-LICENSE.txt` |
| `JetBrainsMono-Regular.ttf` | [JetBrains Mono](https://www.jetbrains.com/lp/mono/) | SIL Open Font License 1.1, see `JetBrainsMono-LICENSE.txt` |

The subsets come from [Fontsource](https://fontsource.org). Characters
outside them fall back to egui's built-in fonts.
