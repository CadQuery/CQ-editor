# Keyboard and mouse reference

On macOS, **Ctrl** means **Cmd**.

## Global shortcuts

Global shortcuts wait while a dialog asks a question (unsaved changes, a
file changed on disk, a message, the command palette…): answer or close
it first, so nothing changes behind it.

| --- | --- |
| New | Ctrl+N |
| Open… | Ctrl+O |
| Save | Ctrl+S |
| Save As… | Ctrl+Shift+S |

| Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab, or Ctrl+PageDown / Ctrl+PageUp |
| Quit | Ctrl+Q |
| Undo (in the editor) | Ctrl+Z |
| Redo (in the editor) | Ctrl+Y or Ctrl+Shift+Z |
| Toggle Comment | Ctrl+/ |
| Auto-Complete | Ctrl+Space or Alt+/ |
| Search | Ctrl+F |
| Replace | Ctrl+H |
| Go to Line… | Ctrl+G |

| Preferences… | Ctrl+, |

### Run and debug

| Command | Shortcut |
| --- | --- |
| Render | F5 |
| Profile (render and time each line) | Alt+F5 |
| Debug / Stop Debugging | Ctrl+F5 |
| Stop (interrupt the script or console command; again to restart Python) | Ctrl+Shift+F5 |
| Step | Ctrl+F10 |
| Step In | Ctrl+F11 |
| Step Out | Ctrl+Shift+F11 |
| Continue | Ctrl+F12 |

Pressing F5 while a script is already rendering queues one more run, which
starts as soon as the current one ends.

## Editor

| Key | Action |
| --- | --- |
| Tab / Shift+Tab | Indent / unindent the line or the selected lines |
| Enter | New line with automatic indentation |
| Click on a line number | Toggle a breakpoint |
| In the completion popup: ↑ ↓, Enter or Tab, Esc | Choose, accept, close |
| In the search bar: Enter / Shift+Enter, Esc | Next / previous match, close |
| In the replace field: Enter | Replace the selected match and select the next one |
| In the *Go to line* bar: Enter, Esc | Go, close |

Undo and redo act on the editor only while it has the keyboard focus; the
console input and the search fields keep their own undo.

## Console

| Key | Action |
| --- | --- |
| Enter | Run |
| Shift+Enter | New line |
| ↑ / ↓ | Input history |
| Tab | Complete |

## 3D view

| Action | Mouse |
| --- | --- |
| Orbit | Left or right drag (around the point under the pointer) |
| Pan | Middle drag, or Ctrl + left drag |
| Zoom | Wheel or pinch (toward the pointer), or Shift + left drag |
| Select according to the toolbar mode (Auto, Object, Face, Edge or Vertex) | Click |
| Add/remove a second measured entity, or add/remove an object in Object mode | Ctrl + click |
| Clear the selection | Click on empty space |
| Zoom to an object | Double-click |
| Look from a side, edge or corner | Click the navigation cube |
| Roll 45° | Click a curved arrow above the cube |
